# NicoCache_nl のインストール（Windows）

## MSI を使う方法（推奨）

1. [GitHub Release](download.md) から `NicoCache_nl-<version>.msi` と対応する SHA-256 ファイルを取得し、ハッシュを確認します。
2. MSI を開き、インストール先とショートカットを選んで完了します。
3. スタートメニューまたはデスクトップの **NicoCache_nl** を起動します。
4. 初回セットアップで、次を確認・選択します。

   - 利用者データの保存先（キャッシュ・追加フィルター・Extension・証明書を保存）
   - HTTPS を有効にして証明書を生成するか
   - CA 証明書を現在の Windows ユーザーの信頼済みルートへ登録するか
   - Windows の自動プロキシーを有効にするか
   - ログオン時に起動するか

5. 適用結果を確認して NicoCache_nl を起動します。`http://127.0.0.1:8080/` をブラウザーで開き、バージョンが表示されればプロキシーは起動しています。

HTTPS を有効にする場合、CA 証明書の登録には Windows の確認画面が表示されます。内容を確認して承認してください。Firefox が Windows 証明書ストアを利用しない設定では、生成された `certs/ca.cer` を Firefox の認証局証明書としてもインポートし、「この認証局によるウェブサイトの識別を信頼する」を選びます。

初回セットアップの適用に失敗した場合は、今回作成した設定と OS 変更を復元し、結果画面から再試行できます。詳細は利用者データの `data/setup-windows-error.txt` に保存されます。

## ZIP を使う方法

ZIP を任意の書き込み可能な場所へ展開し、展開先の `NicoCache_nl.exe` を起動します。初回起動ウィザードは MSI と同じです。`Program Files` のような保護された場所に ZIP を展開して直接編集することは避け、個人のフォルダーを使用してください。

## 確認と停止

起動後は `http://127.0.0.1:8080/proxy.pac` を開けることも確認してください。ブラウザーで動画を再生した後、利用者データの `cache/` にファイルが作成されればキャッシュが動作しています。

停止は GUI の終了操作を使います。`java.exe` や `javaw.exe` を名前だけで強制終了すると、別の Java アプリケーションまで停止するおそれがあります。

## アンインストール

Windows の「インストールされているアプリ」から MSI をアンインストールします。初回セットアップで変更した CA 証明書、Windows 自動プロキシー、自動起動は、保存された変更前状態を使って復元されます。利用者データは意図的に残るため、不要な場合だけ内容を確認して手動で削除してください。
