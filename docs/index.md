# NicoCache_nl とは

NicoCache_nl は、ニコニコ動画向けのローカル HTTP/HTTPS プロキシー兼キャッシュサーバーです。ブラウザーとニコニコ動画の間で動作し、動画・サムネイル・ページ用資材をローカルに保存して、次回以降の再生や表示を支援します。

## できること

- 現行の DOMAND/CMAF を含む動画キャッシュを保存し、ネットワークに接続できない場合にも保存済みの動画を再生する
- `cache/` の動画、`thcache/` のサムネイル、コメント保存などを管理する
- `/local/` で JavaScript・CSS・HTML などを配信し、`nlFilters` でニコニコ動画のページを置換する
- Java Extension でプロキシーの処理、書き換え、完了通知などを拡張する

HTTPS の通信内容を扱うには、初回セットアップで HTTPS と証明書の信頼を有効にする必要があります。証明書を信頼しない構成では、HTTPS のキャッシュ・書き換えは利用できません。

## はじめに

Windows では、GitHub Release の MSI または ZIP を使うのが推奨です。専用 Java ランタイムを含むため、Java・Apache Ant・PowerShell 7・7-Zip を別途導入する必要はありません。初回起動時に、利用者データの保存先、HTTPS 証明書、Windows の自動プロキシー、ログオン時起動を選べます。

1. [ダウンロード](download.md) から現行の配布物を入手する
2. [Windows のインストール](install-win.md) に従い、初回セットアップを完了する
3. NicoCache_nl を起動し、`http://127.0.0.1:8080/` を開いてバージョンが表示されることを確認する
4. ブラウザーで動画を再生し、利用者データフォルダーの `cache/` に保存されることを確認する

手動配置や Unix 系での起動は [各 OS の手順](install-linux.md) を参照してください。

## ファイルの置き場所

Windows パッケージ版は、アプリケーション本体と利用者データを分けます。更新・再インストールで個人のキャッシュや設定を上書きしないためです。

| 種類 | 保存先 | 扱い |
|---|---|---|
| アプリケーション | MSI または ZIP の導入先 | 本体、既定の `local/`・nlFilter、サンプル Extension。手編集しない。 |
| 利用者データ | 初回セットアップで選ぶ場所（既定候補: ドキュメント内の `NicoCache_nl`） | キャッシュ、証明書、追加した `local/`・`nlFilters/`・Extension、個人設定。 |
| 設定の接点 | アプリケーション側の `config.properties` | `userDataRoot` に利用者データの絶対パスを保存する。 |

標準資材を先に読み、利用者データ側の同名ファイルを後から適用します。カスタマイズは利用者データ側に置いてください。

## 安全上の注意

- CA 証明書の信頼と Windows の自動プロキシーは、内容を理解し、初回セットアップで明示的に選んだ場合だけ有効にしてください。
- `certs/` には秘密鍵が含まれます。共有、公開、コミットをしないでください。
- 不具合報告のログや画面にはユーザー ID・URL などが含まれることがあります。公開前に確認してください。
- 標準外の nlFilter・Extension は信頼できる配布元のものだけを追加してください。
