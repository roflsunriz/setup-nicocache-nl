# NicoCache とは？
<div style="text-align: right;">最終更新日：2026/03/14</div>
---

## 動画の自動キャッシュ機能
NicoCacheはローカルプロキシーサーバーとして動作し、ニコニコ動画でユーザーが動画を再生すると、自動でデフォルトでは`C:\NicoCache_nl\cache`に`sm9low[360p-lowest,128]_新・豪血寺一族 -煩悩解放 - レッツゴー！陰陽師.hls`のような形式でキャッシュファイルを作り、再度同じ動画を再生したときにこの動画ファイルを再生しネット帯域を節約するソフトウェアである。

## NicoCache_nlとは？
かつて本家 NicoCache, その派生版の NicoCache_u や NicoCache_p, NicoCache_nl などがあった。現在までメンテナンスが続いているのが本家から分派した NicoCache_nlである。

## ページ書き換え機能
プロキシーサーバーとしての特徴を活かして、ニコニコ動画の好きなページに任意のスタイルやスクリプトやHTMLスニペットを埋め込むことが可能である。nlFiltersという機能で実現されている。

## 拡張機能
NicoCache 用の拡張機能(extensions)という機能がある。Javaファイルとして作り、コンパイルすることで独自の機能を付加することが可能である。

## サムネイルキャッシュ
動画のサムネイルもローカルファイルに自動キャッシュする。表示が高速になる。
