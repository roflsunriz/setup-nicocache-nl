# サポートサイト

最初に[トラブルシューティング](./trouble-shooting.md)で原因を切り分け、内容に合うGitHubの
窓口を選ぶ。

- [使い方・設定の質問（Q&A）](https://github.com/roflsunriz/NicoCache_nl/discussions/categories/q-a)
- [新機能・改善の提案（Ideas）](https://github.com/roflsunriz/NicoCache_nl/discussions/categories/ideas)
- [不具合・ドキュメント報告（Issues）](https://github.com/roflsunriz/NicoCache_nl/issues/new/choose)
- [セキュリティ脆弱性の非公開報告](https://github.com/roflsunriz/NicoCache_nl/security/advisories/new)

脆弱性の詳細は公開Issue、Discussion、掲示板へ書かない。通常の不具合では版、OS、導入方法、
再現手順、期待した結果、実際の結果をフォームに記入する。
